# Evidence standard
Record timestamp, run ID, environment, build, agent, case, actor alias, steps, expected and actual outcomes. Use screenshots, browser traces, sanitized responses, logs, or reproducible command output appropriate to the claim.
Raw evidence stays in ignored run evidence/private directories. Name each file `<CASE-ID>-<step>-<UTC timestamp>.<ext>` (for example `ACCESS-001-03-20260923T101500Z.png`) so a result, its step, and its moment are recoverable from the filename alone. A screenshot must show the state the note asserts; save console errors and the relevant request or response as redacted text when they support a finding. Never store passwords, OTPs, full cards, session cookies, tokens, real patient information, or phone numbers in tracked reports. Review screenshots and traces before external sharing.
Results include relative evidence paths and a concise explanation. References to ignored evidence are local and must be transferred securely if another machine needs them. Evidence references must resolve at recording time; they are not proof that the claim was reviewed.
Retain raw evidence locally for 30 days by default, subject to product requirements; deletion is manual and documented. Keep sanitized findings/history. Do not delete unresolved critical evidence without an owner decision.
