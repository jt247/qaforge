# Admin Notes (example product)

A synthetic product folder. It exists so you can see a fully populated example
before you add a real one. Copy this directory to `products/<your-slug>/`,
rename the slug and name in `product.json`, replace every file below with your
own confirmed information, and delete this folder when you no longer need the
reference.

Admin Notes is an imagined multi-tenant notes web app: users belong to
organizations, notes belong to a user, and notes can be shared inside an
organization. Nothing here points at a real system and no environment is
enabled.
