# Admin Notes QA guide (example)
Read the shared standards first, then this guide, then work the catalog.

Scope for a real copy of this folder: sign-up and session lifecycle, note
create/edit/delete with persistence, note sharing inside an organization,
organization isolation, member invitation and role changes, input validation on
note fields, and sensitive-data exposure in API responses.

Confirm the authentication model, the full role inventory, and the primary
business workflow before creating accounts. The starter catalog is a coverage
floor, not a complete suite. Do not infer features from the product name.
